# 🛒 E-Commerce Web Application

**E-Commerce** is a modern, fully functional e-commerce web app that allows users to explore products, manage their cart, place orders, and track delivery statuses. It features real-time API integration, secure authentication, and advanced data handling using React Query.

🌐 **Live Demo:** [https://e-commerce-rosy-psi.vercel.app/](https://e-commerce-rosy-psi.vercel.app/)

---

## 🚀 Features

- 🔐 **Authentication** – Register, login, and protected routes with JWT tokens
- 📦 **Orders Page** – View all order details (payment, delivery status, etc.)
- 🛍️ **Product Display** – Dynamically fetch and show all available products
- 🛒 **Shopping Cart** – Add/remove items and track total cost
- ⚡ **React Query** – Efficient data fetching, caching, and background sync
- 📡 **API Integration** – All data is managed via RESTful backend API
- 🎨 **Responsive UI** – Built with Tailwind CSS for all screen sizes
- 🧠 **Context API** – Manage global states like cart and user authentication
- 🔄 **Routing** – Smooth navigation using React Router DOM
